# All-Short

Texts and news for the [All-Short](https://routinehub.co/shortcut/8997/) shortcut.

| File | Content |
|---|---|
| `language_de` | German texts (JSON) |
| `language_en` | English texts (JSON) |
| `News.md` | All-Short news shown in the shortcut |

All-Short downloads these files from `raw.githubusercontent.com`. When you change texts, bump `version`,
otherwise devices keep their cached copy.
